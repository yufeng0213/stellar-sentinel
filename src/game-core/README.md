# game-core

纯规则层。这里放角色、地图、判定、战斗、NPC 等可测试的规则。

## 约定

- 不依赖 Vue、DOM、网络、系统时间
- 所有随机数来自 `createRng(seed)`，同一个种子必须得到同一局
- 输入 state，返回事件或结果；不在这里写文案
- state 必须可 JSON 序列化，方便存档与回放
- 叙事文案与 LLM 放在 `src/views/` 或后续的 `src/game/`；AI 只负责措辞

## 当前模块

| 文件 | 职责 |
| --- | --- |
| `rng.js` | 种子随机：`next / int / pick / chance / shuffle` |
| `data.js` | 8 属性、ABO、职业、物品、区域、配方 |
| `chargen-data.js` | 6 人种、26 出身、8 图景、10 气味、11 能力、10 缺陷、12 特质 |
| `character.js` | 草稿校验、属性点、修正、perks、角色派生 |
| `procgen.js` | 10 层 3 幕的节点图生成（同 seed 同图） |
| `run.js` | 移动、采集、事件、休整、扎营、锻造、装备、商店 |
| `combat.js` | 3 AP、手牌、敌方意图、士气、状态、非致命处置 |
| `steal.js` | 敏捷扒窃：NPC / 商店判定与后果 |
| `npc-tags.js` | 126 个 NPC 标签、群体、相容度与玩家派生标签 |
| `npc-events.js` | 每日/周事件、收件箱、约定与奖励 |
| `npc.js` | 性格、四轴关系、送礼/交谈、标签生成、日程 tick、NPC-NPC 关系网 |
