# 星穹哨向 · Stellar Sentinel

星际背景的哨兵 / 向导 RPG。**Phase 0–54 已完成**：路由化的手机优先界面、五步角色创建、程序化星区、采集、事件选择、交易、背包、锻造、卡牌战斗与牌组构筑、同伴参战、多阶段 Boss 与情报、NPC 标签与关系网、约会节点、星区档案、远征契约、城市长期发展、偷窃/通缉、方舟据点、NPC 自主人生、据点压力导演与后续事件链、探索点深潜与深层遭遇、幸存者后续、边境战争、战后后果与城市重建、设防巡逻、LLM 流式对话，以及存档导入导出。

剩余的内容扩充与增强项见 [`PLAN.md`](./PLAN.md)。

- 前端：Vue 3 + Vite + Vue Router + Pinia
- 后端：Express，静态资源、存档 KV、LLM 配置代理
- 规则：`src/game-core/`，纯 JS，固定随机种子
- 端口：前端 `5174`，接口 / 容器 `3003`

## 运行

需要 Node 20+。

```bash
npm install
npm run dev
```

打开 `http://localhost:5174`。生产模式：

```bash
npm run build
npm start
```

## 已实现

- **路由化界面**：hash 路由，手机底部导航在星图 / 背包 / 锻造 / 通讯 / 角色之间整屏切换，返回键可用。
- **五步角色创建**：身份（人种 / ABO / 气味）→ 职业与 26 种出身 → 图景与 11 项能力 → 8 项属性与 10 项缺陷 → 12 项特质与确认。支持随机开局与读档。
- **角色深度**：8 项属性（含敏捷与机缘）、22 点分配；缺陷换取点数；图景提供先手、低血增伤、精神抗性、再生等被动；气味、人种、能力与缺陷会改变 NPC 的第一印象。
- **桌面可读性**：窗口宽度 ≥900px 时界面按 1.5 倍缩放、字号最低 14px，内容宽度扩到 1450px；手机仍保持紧凑布局。
- **页面拆分**：通讯拆成收件箱 / 名册 / 关系网 / 动态四个路由；NPC 资料、探知档案、记忆、赠送、对话各自独立页面，不再全部堆在一个弹窗里。
- **地下城地图**：星图改为从左往右推进的房间格，节点之间留有明显间距，用直角折线连接；横向滑动查看整层，当前房间自动居中，已探索 / 可前往 / 未连通状态直接落在格子上。
- **战败回城**：战斗失败不再卡死。角色会被拖回空港，推进到第二天并恢复部分生命/精神，星图重新排布，背包、关系与角色成长保留。
- **开局剧情**：10 个醒来场景（冷冻舱、坠毁舰桥、雨夜巷口、矿难废墟、白塔地下层、边境列车、孢雾林、静默教堂、黑市诊所、沙暴哨站）；本地开场立即显示，模型可展开更具体的感官叙述；开场选择接第一次 d20 判定，结果写回存档。
- **空港城市**：独立地点页面的市场 / 酒馆 / 诊所 / 城门；买酒、材料、药品，按配方制药，治疗，购买每日货架；酒馆访客可花信用点刷新，新 NPC 带标签、关系和关系网，旧访客离开。
- **主线章节**：4 章目标链「失联的白塔 → 黑市的价码 → 塔下的矿脉 → 门」，按清理节点、购买情报、清理首领推进；第四章集齐情报、首领记录与门钥，经过两段判定后选择推开门或合上，记录结局；主线页面显示完成条件与章节列表。
- **结局后日谈与收集**：开门/关门 × 判定成功次数得到 4 个结局；结局后生成包含最近 NPC、信用点、战败和地穴名的后日谈；结局记录保存在浏览器 `localStorage`，标题页和独立结局收集页显示解锁数量、首次/最近一次抵达。
- **派系声望**：白塔 / 黑市 / 漂流者 / 低语者四派系，交谈、送礼、城市委托、黑市情报与访客故事都会改变声望；友善后可每天领取对应派系补给。
- **派系任务链与声望商店**：每派系 3 步任务链，按 10 / 30 / 60 声望解锁；可以用信用点 + 声望在派系详情页兑换专属补给。
- **访客个人剧情**：4 套三阶段访客故事（欠债、失踪搭档、离开空港、替人送货），按信任、亲近和信用点解锁，结尾给奖励并提升该 NPC 派系声望。
- **恋爱与表白**：关系分为陌生 / 熟悉 / 好感 / 暧昧 / 恋人五阶段；好感期会出现人设专属试探，接受后才进入暧昧；暧昧阶段才能主动或被动表白；多恋人会触发吃醋事件；NPC 资料页显示阶段和恋人标签。
- **关系维护与冲突**：暧昧 / 恋人关系会因长时间不互动积累压力，压力过高触发争吵并进入冷战；第二天会出现和解事件，可选择道歉、倾听或继续拉开距离；同时有多位暧昧 / 恋人时会触发争宠事件，可以偏袒、两边安抚或划清边界。NPC 资料页显示关系稳定度、冷战状态和恢复情况。
- **约定与失约**：NPC 会请求两天内见一面或带一件东西；答应后进入资料页「约定」列表，见面约定会在星图生成「约会」节点；到期未履行会降低信任、亲近并增加怨念与压力，同时生成失约事件，可道歉补偿、解释或避而不谈。
- **约会 AVG 节点**：赴约进入独立的三幕剧情页面，按 NPC 人设展开不同的见面、聊天和告别文本；每个选择会改变信任、亲近或压力，完成后节点清除、约定结算。
- **NPC 关系树**：每个 NPC 有独立 `/npc/:id/network` 页面，从本人出发用直角分支显示恋人、亲人、好友、对手和熟人，不再只有一张全局关系网。
- **每日结算与 NPC 自主行动**：扎营时弹出 CPU 重算进度条，结算后展示 NPC 当天的动态；NPC 会捡到小礼物、受伤、用掉你送的医疗包，并拥有自己的随身背包；可让模型把当天事件写成 180–320 字的「空港夜报」，失败自动使用本地版本。
- **NPC 交易与求援**：NPC 有信用点和背包，可以在 `/npc/:id/trade` 买他的货或把东西卖给他；每日结算时 NPC 之间也会自主买卖；受伤的 NPC 会通过收件箱向你要医疗包、治疗费，或请你护送他回空港诊所。
- **NPC 收购单与装备**：每个 NPC 每天有一张主动收购单；玩家可以把装备送给 NPC，NPC 的属性会随之提高，并在自主冲突和伏击中使用这些装备。
- **装备成长**：图纸分标准 / 原型，原型图纸由首领掉落；装备带随机词条、套装 2 / 4 件效果与强化，强化消耗信用点和废料；首领情报会揭示弱点，攻击弱点有额外伤害。
- **校准树**：哨兵 / 向导 / 生存三支，每支 5 个节点；点数来自开局、首次精英、首领和章节完成，不需要刷经验；节点直接影响战斗、治疗、商店、夜间探索与移动消耗。
- **装备共鸣**：套装与校准分支组合会触发额外效果，例如白塔 2 件 + 哨兵 2 节点获得额外开局护盾，漂流者 + 生存提高战斗信用点，低语者 + 向导强化灵能牌。
- **战斗稳定性**：修复精神侵蚀敌人结束回合时因效果作用域异常而卡死；进行中的战斗可从星图节点继续进入。
- **物品说明与小礼物**：消耗品直接标出“战斗外使用”和生命/精神变化，精神等同图景稳定度；新增 8 种无属性小礼物（石头、明信片、铜铃、纽扣、骰子、干花、铁皮小兽、没有地址的信），可采集/战斗随机掉落、市场购买、送给 NPC。
- **地穴命名**：本地组合名 + 模型命名候选；名字只改变显示，不影响节点、掉落或难度；战败换图时自动重掷。
- **城市扩展**：任务板每日 3 张交付/清理委托；黑市出售稀有材料与白塔情报；酒馆可打听每日传闻，访客也会进入日常事件池。
- **战斗动画**：出牌斩击、灵能闪光、护盾环、敌人受击抖动、玩家受击、敌方突进、胜利 / 失败入场动画。
- **音效**：Web Audio 实时合成，不需要音频资源文件；按钮与链接点击、战斗出牌、受击、敌方回合、胜利/失败、撤离都有声音。标题、HUD 和战斗页都能一键静音，偏好保存在 localStorage；默认音量已调高。
- **程序化星区**：每个种子生成 10 层、3 幕、约 22 个节点；7 个区域各有配色与掉落，包含采集 / 遭遇 / 事件 / 交易 / 休整 / 首领节点。
- **行动点与判定**：移动、采集消耗 AP；d20 + 属性 + 特质 + 装备对抗 DC，可在任意节点扎营恢复。
- **敏捷玩法**：可对 NPC 或商店扒窃，d20 + 敏捷 + 能力 + 机缘；成功拿走物品或信用点，失败会结怨、惊动摊主。议价、急救、追踪、机械等能力也会进入对应判定。
- **事件与交易**：20+ 类事件、每类多个选项与检定结果；新增被抢、被打、关卡勒索、管道爆裂、旧账、图景侵蚀等坏事件；Omega / Alpha / 向导 / 哨兵身份会抽到专属冲突事件；交易点有商品、价格与库存。
- **卡牌战斗**：21 种动作、25 张起始牌组；3 AP、敌方意图预告、流血 / 眩晕 / 破甲 / 护盾 / 专注 / 闪避 / 反击；敌人有护甲、再生、召唤、狂暴与撤退。打崩士气后可放过、缴械、审问、招募或下狠手。
- **牌组构筑**：战斗胜利后三选一加牌或跳过；精英 / 首领奖励偏向高价值牌；`/deck` 页面可查看牌组、用信用点和废料升级单张牌、删除卡牌；升级牌会改变伤害、护盾或机制，并直接用于后续战斗。
- **同伴参战**：队伍 NPC 拥有 14 种人设支援牌和战斗被动；高信任 / 恋人 / 装备会强化支援，受伤或冷战会削弱；战斗中显示同伴支援条和本地台词。
- **多阶段 Boss**：三种 Boss 档案各有弱点和抗性，血量阈值触发阶段变化；黑市情报揭示弱点、抗性与阶段机制；首杀和重复挑战奖励不同。
- **NPC 规模与名字库**：名字库支持 80 个中文名 + 90 个英文名 × 30 个英文姓的组合；`createNpcWorld` 可生成最多 1000 个 NPC，500 人时自动切换稀疏关系图，并分 core / active / background 三层，背景 NPC 不跑每日关系与事件；空港首次进入会补到 20 个本地人口，访客从本地池轮换而不再无限新建。
- **第二城市节点**：星图第 5 层会出现「矿脉站」城市节点，首次进入生成 14 个本地人口，拥有独立市场、诊所、黑市、任务和访客池；城市状态按 `activeCityId` 分开保存。
- **星区档案**：16 条跨周目成就，分远征 / 关系 / 城市 / 构筑四类；记录 Boss 阶段击杀、低精神胜利、首次约会、和解、履约、第二城市、小牌组等行为，只解锁档案条目不提供战斗数值。
- **远征契约**：每局开局从追猎 / 测绘 / 同行三选一，并抽 2 个星区词条；词条影响命中、治疗、战斗信用点、灵能伤害、商店价格、采集产出、关系压力或每日 NPC 事件；契约进度显示在地图 HUD，完成后自动结算奖励。
- **高危路线节点**：部分战斗/精英节点会标记为高危巡逻、不稳定区或遗存富集；敌人更强、可能多一个敌人，但战斗后额外获得信用点、材料或四选一卡牌。玩家可以在星图上选择安全或高危路线。
- **偷窃败露**：扒窃失败会按 NPC 的攻击性、信任、亲近、怨念和人设分支；温和或高信任对象可能不追究并送你东西，危险对象会直接动手进入 NPC 战斗，普通对象则警告并扣关系。
- **城市通缉**：商店扒窃失败会提升通缉等级，最高 3 级；通缉会提高城市价格，城市页显示悬赏横幅和罚金，可以缴纳罚金清除，每 3 天未再犯案自动降低一级。城门盘查还允许声望 30 的派系出面降低一级，声望 60 的派系可直接撤销案件，消耗信用点和声望。设防重建后的城市会派出巡逻队：通缉 2 天即可衰减，商店扒窃败露额外提升一级通缉。
- **方舟据点**：玩家拥有容量 4 人的「渡鸦号」，必须主动邀请信任的 NPC 入住；成员可以安排到医疗舱、工坊、档案室或温室，完成远征后在据点休整，按设施产出物资，匹配人设会提高产出。居民有安全 / 归属 / 意义需求和心情，休整会触发争吵、思乡、受伤或意外收获等据点事件；14 种人设还各有一次专属据点事件。
- **NPC 自主人生**：每个 core / active NPC 有个人目标、三项需求和派系等级；会在玩家远征时晋升、结伴、结仇、离城、归来，需求长期过低会降低工作效率、触发争吵、离队或事故，严重时死亡并由最亲近的 NPC 继承遗产。
- **据点压力导演**：休整事件按平静 / 紧张 / 混乱三档压力生成；平静有访客和旧货，紧张有争吵、思乡、伤病和派系施压，混乱有袭击、叛逃、火灾和偷窃。部分选择会留下两三天后触发的后续事件链。
- **探索点深潜**：星图第二、三幕会出现 3 层探索点，每次深入消耗 1 AP 且难度递增；第一层出材料，第二层出旧芯片，第三层出遗物，失败会扣生命和精神。每层可选择破拆 / 扫描 / 潜行，三种方式属性、DC、奖励和失败代价不同；第三层入口会遇到守门者、机关或幸存者，守门者可以进入真正的卡牌战斗，幸存者可以救回空港成为新 NPC。救回的幸存者两天后会触发「想回那扇门看看」专属后续。
- **边境战争**：签订城市盟约后，城门会出现四阶段战争线「集结 → 营地 → 敌方据点 → 回城结算」；敌方据点是真实卡牌战斗，胜利后决定由派系接管、城市自治还是把物资带回方舟。战后会改变城市控制方，敌对 NPC 可能迁出，同派系 NPC 改变态度，并留下伤者。城市随后进入重建阶段，可选择设防、民生或开放，并在两天后验收，有机会接回迁出者。重建政策会成为长期城市效果：设防提高治疗并派出巡逻队，民生提高治疗与精神恢复，开放增加市场库存并降低价格。
- **城市长期发展**：每座城市可升级诊所、市场、锻造间和通讯塔，各 3 级；四个派系各有城市项目「白塔信标 / 市场联运 / 拾荒路网 / 静默室」，需要声望与材料，完成后提升派系影响力并提供长期效果。城市项目完成后可以签订一个城市盟约，提升对应派系并排斥敌对派系。
- **NPC 自主活动**：18 名 NPC，每人带 5–7 个标签，各自有性格、兴趣、派系、日程与记忆；四轴关系（信任/尊重/亲近/畏惧）+ 怨念，送礼会饱和，初始印象天然有高有低。
- **NPC 标签**：126 个标签，分出身 / 性格 / 信念 / 职业 / 怪癖 / 关系 / 身体 / 阴影 8 类；标签会改写五轴性格、初始关系、战斗数值、兴趣、事件权重和 NPC 之间的相容度。玩家也会从人种、出身、图景、缺陷、能力和特质派生标签，影响 NPC 的第一印象。
- **NPC 人设原型**：14 种高于标签的戏路，包括阴湿男鬼、干燥男鬼、嘉豪、阳光、霸总、傲娇、疯批、病娇、清冷高岭、忠犬奶狗、腹黑、靠谱人夫、钓系、糙汉；原型会改写性格、兴趣、初始关系、日常消息和 LLM 对话 prompt，并显示在 NPC 资料页。
- **人设专属事件**：每个原型有一条只在信任达标后出现的收件箱事件，例如阴湿男鬼的「门外的影子」、傲娇的「不是给你的」、腹黑的一笔交易；每条事件只触发一次，带独立选项和关系后果。
- **NPC 主动事件**：每日 1–2 条、每周 1 条大事件；信息、送礼、求助、邀请、靠近、冲突、八卦按标签、关系和冷却加权；收件箱可直接处理，接受邀请会在地图上生成约定节点与奖励。
- **探知档案**：NPC 详情里的「探知 · 公开档案」按钮才生成，不预生成；5 个关系阶段、每人 15 条，阶段锁定，每次只展开一条；优先用 LLM，没有 Key 或失败时回退本地档案。
- **事件细读与长期记忆**：收件箱事件可点「细读」，按需生成 2–3 句叙述；每周结束自动把直接互动整理成 NPC 长期记忆，并注入对话与探知 prompt。
- **关系网与队伍**：NPC 之间有独立关系，标签相容度决定天然亲近或冲突，每日扎营会自主活动、关系漂移、传播八卦；信任足够可组队，队员会在战斗中提供「同伴支援」；交恶会警告、偷窃甚至伏击。
- **LLM 流式对话**：NPC 详情页有独立聊天面板；人格、四轴关系、日程和记忆会进入 prompt，回复逐字流式显示；没有 Key 或请求失败时自动降级为本地对白。
- **行为白名单**：模型只能提议 `offer_party` / `warn` / `leave`，由本地规则校验后执行；不能直接改数值。
- **背包与锻造**：材料、消耗品、装备、品质（粗糙 / 标准 / 精良），装备加成直接进入判定。
- **存档管理**：当前存档可导出 JSON、导入旧存档、删除本局；导入时会校验并补全 NPC 世界、聊天记录与调用预算。
- **LLM 配置**：OpenAI 兼容 / Anthropic / Ollama；服务端保存 Key、掩码回传、连通性测试；输出上限 8192 tokens，单次最多 120 条消息、单条 40 万字符、总上下文 90 万字符，并处理没有结尾空行 / `[DONE]` 的最后一帧。NPC prompt 把稳定人设放在前、动态状态放在后，便于 DeepSeek 前缀缓存命中。
- **日志**：判定与拾取记录在角色页可以看到。

## LLM 配置

在 `/settings/llm` 选择 provider，填写 Base URL、模型名与 API Key，点击「测试连接」。

- Key 只写入服务端 `data/kv.json`，前端只拿到掩码与 `hasKey`
- 接口：`GET/PUT /api/llm/config`、`POST /api/llm/test`、`POST /api/llm/chat`（SSE 流式）
- 模型只负责对白、描述与行为提议，不参与数值判定
- 每局对话预算 120 次；无 Key、超时或请求失败时自动使用本地对白
- 如果服务暴露到公网，请自行加访问控制或改用环境变量注入

## 约定

1. **规则与叙事分开**：`game-core` 不读 DOM、不调用网络、不写文案。
2. **随机可复现**：规则层只用 `createRng(seed)`，同种子同操作得到同一结果。
3. **AI 不碰数值**：LLM 只生成文本或提交受白名单约束的行为提议。
4. **存档可序列化**：当前使用 localStorage，已支持导入导出；服务端同步仍待做。

## Docker 部署

默认按子路径 `/stellar-sentinel/` 部署，容器端口 **3003**。

```bash
docker compose up -d --build
docker compose ps
```

容器内直接访问：

- `http://127.0.0.1:3003/stellar-sentinel/`
- 健康检查：`http://127.0.0.1:3003/api/health`

存档保存在宿主机 `./data/kv.json`（挂载到容器 `/data`），备份时整个 `data` 目录拷走即可。

### 域名与 Nginx

如果域名的根路径已经被其他站点占用，在 Nginx 里增加一个 `/stellar-sentinel/` 的 location 即可，示例见：

```
deploy/nginx.stellar-sentinel.conf
```

关键配置：

```nginx
location = /stellar-sentinel {
    return 301 /stellar-sentinel/;
}

location /stellar-sentinel/ {
    proxy_pass http://127.0.0.1:3003;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 300s;
}
```

`proxy_buffering off` 必须保留，否则 LLM 的 SSE 流式回复会被 Nginx 缓冲。

### 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `3003` | 容器监听端口 |
| `BASE_PATH` | `/stellar-sentinel` | 子路径部署；设为空则部署在根路径 |
| `DATA_DIR` | `/data` | 存档目录 |
| `TZ` | `Asia/Shanghai` | 时区 |

### 只用 Docker，不用 Compose

```bash
docker build -t stellar-sentinel:latest .
docker run -d --name stellar-sentinel \
  -p 3003:3003 \
  -e PORT=3003 \
  -e BASE_PATH=/stellar-sentinel \
  -e DATA_DIR=/data \
  -v $(pwd)/data:/data \
  stellar-sentinel:latest
```

### 直接访问根路径

容器同时兼容根路径和 `/stellar-sentinel/`。如果 Nginx 选择剥掉前缀再转发，也可以正常工作；此时 `BASE_PATH` 可以留空。
